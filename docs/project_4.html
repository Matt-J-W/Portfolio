Matthew Webb

2026-01-20

Context

This fictional dataset contains information about patients stays at hospital including some demographic info and information about their reason for attendance. I will use this to create insights on healthcare trends in order to inform trusts about growing concerns around patient safety.

This data was sourced from Kaggle and uses the following tools: Pandas, Matplotlib, Seaborn, ANOVA, Regression Test, Chi-Squared Test

Approach

My goal with this data is to determine what effects the billing price for a patient, I will be running some ANOVA and regression tests on some of the variables to determine their relationship with billing. Then I will be able to conclude where hospitals need to be focusing their attention to reduce these costs.

Data Cleaning

Again we have an even spread of data in our variables with no missing or erroneous values, this means we won’t need to do much cleaning but I’ll fix the naming conventions as there is a mix of upper and lower case in the words, and my date variables need converting. Finally, as I have admission and discharge date I can calculate a length of stay variable.


# Converting the name columns, first creating a new dataframe so I leave the original intact
p4_data_cleaned = p4_data_import
p4_data_cleaned.columns = p4_data_cleaned.columns.str.lower().str.replace(" ", "_")

# Converting the name column
p4_data_cleaned["name"] = p4_data_cleaned["name"].str.title()

# Converting the date columns and creating LOS column
p4_data_cleaned["date_of_admission"] = pd.to_datetime(p4_data_cleaned["date_of_admission"], yearfirst = True)
p4_data_cleaned["discharge_date"] = pd.to_datetime(p4_data_cleaned["discharge_date"], yearfirst = True)
p4_data_cleaned["length_of_stay"] = (p4_data_cleaned["discharge_date"] - p4_data_cleaned["date_of_admission"]).dt.days

ANOVA Test

This simple test is important as it will determine if there is significance in the difference in billing between the types of admissions, i.e. do they cost different amounts.

# Running an ANOVA test and pulling the f-statistic and p-values to test for significance
urgent_anova = p4_data_cleaned[p4_data_cleaned.admission_type == "Urgent"]["billing_amount"]
emergency_anova = p4_data_cleaned[p4_data_cleaned.admission_type == "Emergency"]["billing_amount"]
elective_anova = p4_data_cleaned[p4_data_cleaned.admission_type == "Elective"]["billing_amount"]

# Getting the results
f_statistic, p_value = f_oneway(urgent_anova, emergency_anova, elective_anova)

# Creating a plot to visualise the results

The results of my ANOVA shows no significance between the billing amount and whether the admission type is urgent, elective or emergency (f_statistic = 0.28, p_value = 0.75). This suggests that current hospital pricing is standard across admission types and doesn’t need amending. However, I do now need to dig deeper to look for variability.

Conclusion

I found no significant relationships between my variables and billing amount, indicating there is no one factor that is costing hospitals / patients more than others. I would still bring this to hospitals attention as while it seems like there is consistent pricing it could potentially mean that hospitals need to review their pricing. For example I would assume length of stay would impact the cost of billing, with shorter stays being cheaper, so there may be some incorrect accounting going on.

The results of my chi-squared test shows no significance between medical condition and test results, showing no one condition produces more inconclusive results than others and would therefore need to be brought to hospitals attention.
